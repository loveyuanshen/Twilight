## 即时通讯

- 微信
  app store中有,不必多提. Mac端的微信很轻量,占用1.7GB左右.和Android端动辄3-7G的内存相比算是很良心了.

- QQ/TIM
  同样是国民级的通讯软件.但我没有使用QQ的习惯,故不作评价.

## 视频软件

- piliplus
  b站第三方客户端,内存占用小,功能全面



## 浏览器



- Safari
  Mac自带的浏览器,突出的特点是省电和隐私防护.
  但是扩展需要收费,占用奇高这点无法理解
  甚至连置空cookie的选项也藏的很深,有很高的学习成本
  速度还是挺快的,日常使用完全够了

- chrome
  老牌浏览器,网站显示效果测试经常用到.
  能直接接入MCP提供给codex这点还是可圈可点的,便捷性很高
  但是内存占用的老毛病还是存在,开十多个标签页电脑就开始明显升温了.

- edge
  微软出品的流氓软件<相对而言>,在windows中是内存大户.
  在Mac效果不错,算得上中规中矩.
  与Andriod端edge的同步很好用.

## 清理和系统优化

- 柠檬清理
  腾讯出品的清理软件.目前为止很良心,没有广告弹窗和流氓行为
  用于优化腾讯系软件空间占用有奇效.普通用户用这个就够了

- pear cleaner
  GitHub有名的Mac卸载工具,能准确识别软件创建的文件,在卸载时一并删除.

- mole(命令行版)
  使用homebrew安装,在终端使用.清理效果很好,几乎不占内存,且无需付费.

## 防火墙

- lulu
  Mac上的类似软件只推荐这一个.GitHub开源软件,能够管理出站和入站的连接.比Mac原生防火墙的阻止传入多了阻止传出连接的功能.当下载的软件试图连接某个IP时,lulu会弹窗显示连接IP和授权请求.

## 小工具

- vorssiant
  小工具的聚合软件,已经在GitHub开源
  软件整合了很多付费软件或零散小工具的功能,比如剪贴板历史,功耗菜单栏显示,使用快捷键快速调用,属实良心,用一个软件解决了需要安装三四个软件才能实现的便捷操作.

- localsend
  开源的本地局域网文件互传工具,开箱即用
  支持win/Mac/Andriod/linux
  传输速度快,有剪贴板同步

- Cyberduck
  不错的网盘挂载工具.免费版就够用.



## 笔记软件/markdown编辑器

- obsidian
  常见笔记客户端.需要折腾设置和插件,作知识库似乎不错
  同步可借助remotely save插件实现

- notion
  类似国内的语雀,支持多人协作,见过有人把它当作数据库或者单纯博客使用
  -markra
  轻量化markdown笔记软件,有AI功能,同样是开源,小巧精美.这篇blog使用了lmarkra完成编辑.



## Agent

### 探索历程

购买这台Mac之前,Android端一直在使用Rikkahub.软件集成了web-search和agent记忆,MCP等功能,甚至包含了简单的Rootfs工作区环境.
但是rikkahub的作者专注于Android端软件的开发,在issue中明确表示未来不会开发pc端,为了在Mac上也能获得类似的体验,我寻找了大量有类似功能的软件.

### 常用的工具

- Claude code
  最常见的coding工具.有GUI和命令行两种形式

注意:国内用户需要安装类似cc-switch的工具来接入第三方模型

优点:生态良好,工具齐全,用户众多,适合干重活(跑大型任务)
缺点:只有接入Claude本家的模型才能将其能力最大化,且Claude的模型价格奇高,对中国用户极不友好,接第三方模型有概率掺屎导致缓存命中降低,模型变蠢;



 期待国模早日超越Claude!

- codex
  openai家的编程工具,能力与Claude code相差不大.使用一个ke y即可登陆使用,不怎么卡中国用户,同样有GUI和cli,computer use是其的特色工具,但还是需要自家模型.
  缺点:对话只能归档不能直接删除,需要接cc-switch或codex++改配置
  总结:claude code平替

- open code
  GitHub完全开源的编程工具,生态较好,用户数处于增长阶段
  支持直接接入第三方API
  5美元套餐能够畅享各种国产模型,宣传“量大管饱”,coding套餐的爹

- live agent
  L站的某个技术力Max的佬研发,轻量化为主,界面美观,非常适合小白
  原生支持接入第三方模型,支持corn定时任务和常用的功能,适合日常使用
