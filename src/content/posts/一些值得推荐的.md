# 《西窗法雨》

:::note
内容生动，通过实例由浅入深阐述，作者直接表明的看法较少，侧重引导读者自行理解，篇幅短小精悍，适合法学入门
:::

#  《法治及其本土资源-苏力教授》

:::note
篇幅较长，侧重论述和说理，观点具有思辨性.读完后再作补充
:::

#  《乌合之众》

:::note
社科类经典著作.观点很尖锐且具有跨时代价值.对社会结构和群体的分析极为透彻，不可多得的好书，值得反复阅读.
:::

# 《圆圈正义》

:::note
罗老师的名作，适合大众群体阅读，没有大量的说理引用，思维清晰.《圆圈正义》是其早期作品的合集，能从多重角度窥见法律人内心的朴素正义情节，从“城管抽梯案”到舆论和司法关系的辩证看待，无不彰显出法治素养.后作《法治的细节》中部分访谈节目无聊且冗长，阅读价值不如前面的文章
:::

# 《后真相时代》

:::note
最早是做某年藜麦高考题入坑的，读起来颇有趣味，没有过多评价，常看常新 
:::
